# Keystroke 1.5.0

Released September 29, 2026.

A contributors' release. Two new extensions open a browser profile and
reopen a recent editor project. Clipboard history can paste straight into
the window you came from, and Cursor joins the assistants under *Continue
with*. Thanks to Thomas Torggler, Pablo Pineda and Jordi López, who wrote
them.

## New

- **Browser profiles** (extension, by Thomas Torggler). `profile work`, or
  just the profile's name at the root, opens a new window in that profile of
  Chromium, Chrome, Brave, Vivaldi, Edge, Firefox, Firefox ESR, LibreWolf or
  Zen, native or Flatpak. `Ctrl+↵` opens a private window (Incognito,
  InPrivate or a private window) instead. Profiles are listed under the
  names the browser's own profile menu uses. Only `Local State` and
  `profiles.ini` are read, once per palette open. Off until you turn it on.
- **Recent projects** (extension, by Thomas Torggler). `proj keystroke`, or
  the project's name at the root, reopens a folder, workspace or remote
  (SSH, WSL, dev container) that VS Code, Code - OSS, VSCodium, Cursor or
  Windsurf opened recently, in the editor it was recent in. `Ctrl+↵` opens a
  terminal in its folder. The editors' recent list is read from their
  `state.vscdb`, read-only, once per palette open. Recent single files are
  an opt-in setting. Off until you turn it on.
- **Paste from clipboard history** (by Pablo Pineda). In Clipboard History,
  `↵` still copies an entry and `Ctrl+↵` now pastes it into the window you
  came from, text or image. Settings → Clipboard History → **Paste on
  selection** swaps the two keys. Pasting sends `Ctrl+Shift+V` to a
  terminal (Omarchy's `terminal` tag, or a desktop entry in the
  TerminalEmulator category) and `Ctrl+V` anywhere else. **Paste shortcut**
  can force `Shift+Insert`. Dictation's paste is unchanged.
- **Cursor under *Continue with*** (by Jordi López). With Cursor installed,
  **Ask Cursor** opens the Cursor composer with your prompt through
  `cursor --open-url`, and in CLI mode **Ask Cursor Agent** runs Cursor's
  `agent` in a terminal with the prompt as a literal argument. Settings → AI
  & Web Search can make Cursor the preferred assistant, and **Cursor
  workspace folder** passes `--workspace`.

## Improvements

- **A one-word flag is never an option.** A query that is exactly `-p` or
  `--yolo` reaches `claude`, `codex` and `agent` as text, not as a flag.
- **Provider contract.** Rows may return `{type:"paste", text}` or
  `{type:"paste", mime, path}`: the host copies, closes the palette and
  pastes with the key the focused window expects. See
  [docs/providers.md](../providers.md).

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the
[1.4.0 notes](v1.4.0.md) applies unchanged. The bundled matching engine is
byte for byte the one verified in 1.4.2. Both new extensions need only
Python 3's standard library. Paste uses `wtype`, `wl-copy`, `hyprctl` and
`jq`, which Omarchy already ships.

Validation: the QML suite (270 tests), the extension checks for all eight
extensions, the clipboard, transfer, matching, palette and hotkey checks,
qmllint and plugin validation pass. See the
[verification record](../verification.md).
